# SALP 监控规则手册（A股每日监控执行版）

版本：1.0.0 · 更新：2026-08-02
配套文件：`ashare-watchlist.json`（机器可读清单）、`daily-digest.schema.json`（输出契约）
**本手册与配套清单为主题研究工具，不构成投资建议。**

---

## 一、规则来源：SALP 投资框架的五个核心判断

Situational Awareness LP 的公开信号（13F、官网、论文、媒体报道）所表达的投资规则可归纳为：

1. **稀缺的不只是 GPU**：可并网的可靠电力、可上线的高密度算力园区、HBM/存储、光互连，与加速器同等重要。
2. **执行能力即价值**：把矿场、土地、存量电力改造成 AI/HPC 容量的执行能力，比"拥有资产"本身更重要。
3. **瓶颈决定优先级**：先进封装、HBM、网络互连是把晶圆变成可交付算力的汇合瓶颈，应优先于泛化叙事。
4. **物理量是唯一硬通货**：MW、端口数、堆叠产能、交期、稼动率——证券价格与基金持仓报告值都不是产能。
5. **对冲思维**：对可能落后的环节保持怀疑，任何"规划容量"都必须穿透到 energized 与 contracted。

以下 10 条监控规则（R1–R10）即由此翻译而来，逐条标注了出处，并写入 `ashare-watchlist.json` 的 `salpRules` 字段供 agent 引用。

## 二、十条监控规则（执行版）

### R1 物理口径优先
- **规则**：只记录 MW、台、端口、吨、产能利用率、交期等物理量。股价、市值、基金持仓报告值不得作为产能或供给信号。
- **执行**：agent 每日输出中的每个信号必须带 `physicalMetric` 字段（如无可填 null 并归入 `dataGaps`）。
- **反例**：张江高科股价上涨 ≠ 光刻机进展；某 IDC 市值增长 ≠ 可用算力增加。

### R2 瓶颈优先
- **规则**：监控资源按 NET/SRV/CLG/PWR/MEM/PKG > ACC/FAB/IDC > LIT/REE/MAT/FUL/EDG 排序。
- **执行**：每日监控时间预算有限时，按此顺序裁剪；A/B 级 32 只标的必须每日全覆盖。

### R3 电力分级核实
- **规则**：任何容量声明区分五级状态：`planned → secured → interconnected → energized → firm IT load`。
- **执行**：IDC/PWR 赛道的每条 MW 数据必须带 `powerStage` 标记；只有后两级可计入"可交付"。

### R4 证据等级强制标注
- **规则**：一级（定期报告/公告）> 二级（监管文件/招标中标/海关）> 三级（交易所互动平台）> 四级（行业数据商）> 五级（券商研报）> 六级（媒体）。低等级证据不得单独触发 P0/P1。
- **执行**：每条信号必须带 `evidenceTier` 与 `evidenceRefs`。

### R5 主题共识提级
- **规则**：两个以上独立来源（公司披露+行业数据+政策）同时指向同一环节异动时，提高该环节研究优先级，并生成层级复核候选。
- **执行**：写入 digest 的 `tierReviewCandidates`，季度集中复核。

### R6 衍生品不作方向解读
- **规则**：对任何机构信号（含 SALP 自身 13F），期权 value 既不是权利金也不是净敞口，禁止据此断言多空方向。
- **执行**：涉及外部基金信号时，digest 只记录事实（报告期、发行人、类别），不做方向性结论。

### R7 历史快照标记
- **规则**：一切机构持仓信号必须带报告期标记，默认视为历史快照；报告期后事件单独标注 `postPeriod: true`。
- **参考案例**：SALP 2026Q1 13F 提交后，Axios 报道其向 Citadel 出售全部公开股票组合——该 13F 只能作为历史信号。

### R8 训练≠推理
- **规则**：IDC/EDG 信号区分训练园区（电力/规模导向）与推理节点（延迟/邻近性导向），指标不得混用。
- **执行**：digest 中 IDC/EDG 信号必须带 `workloadType: training|inference`。

### R9 政策即时触发
- **规则**：出口管制、稀土配额/管制、原产地规则、数据主权、并网许可等政策事件对全部关联标的即时触发 P0 评估，不受 cadence 限制。
- **执行**：每日任务开始前先扫描政策源（商务部、BIS、海关、能源局），命中即打断常规流程优先处理。

### R10 容量→收入验证
- **规则**：IDC/SRV 赛道必须交叉验证预租赁率、上架率、合同期限、锚定客户集中度。只有容量无合同 = 降级信号。
- **执行**：IDC 标的的每次评估必须同时给出 MW 数据与合同数据；缺一侧即列入 `dataGaps`。

## 三、Agent 每日执行 SOP

```
1. 加载 ashare-watchlist.json（检查 manifestVersion）
2. R9 优先：扫描政策源 → 命中则对关联 lanes/tickers 生成 P0 告警
3. 按 cadencePolicy 确定当日覆盖集合：
   - 每日：tier A + B（32只）
   - 周一：追加 tier C（20只）
   - 每月首个交易日：追加 tier D（20只）
   - 每季度首月：追加 tier E（20只）+ 全量层级复核
4. 对每只标的：按 lanes 的 coreFields + 标的 notes 采集信号
5. 按 R4 标注证据等级；按 R1/R3 校验物理口径与电力分级
6. 逐条评估 alertTriggers，生成告警（带 severity 与 ruleRefs）
7. 按 R5 聚合主题共识，生成 tierReviewCandidates
8. 输出符合 daily-digest.schema.json 的 digest 文件
9. 数据缺口写入 dataGaps，不得用估算值冒充一级证据
```

## 五、边界

- SALP 规则来自其公开披露与公开报道的**研究性解读**（见 `research/situational-awareness-lp-2026-q1.md`），SALP 本身未发布过面向 A 股的监控规则；本手册是翻译与适配，不是 SALP 的官方方法。
- 2026-07-30 Axios 报道 SALP 已向 Citadel 出售其全部公开股票组合，其 13F 信号应整体视为历史框架参考（R7）。
- 监控输出为研究信号，不构成投资建议；任何交易决策需另行人工判断。
